Working with files

Looking at a file

Three ways to see the file itself rather than what is written about it — and none of them changes anything.

Quick Look

Space opens the file in the large preview window macOS uses everywhere. ⌘Y and View > Quick Look do the same, and the same key closes it again.

This is also how you play a video or a sound file without leaving AssetScout, and how you read a PDF you have just found.

Open

Open hands the file to whichever application macOS opens that kind of file with. A double-click on a thumbnail does the same thing.

Show in Finder

Show in Finder opens the folder the file is in and selects it there — the answer to “fine, but where is it?”, which is usually the question you came with.

The same button sits at the end of the Path row in the inspector, which is closer to hand when you already have the panel open.

Worth knowing

Every action in this menu applies to the whole selection, not only to the item you right-clicked. Ten pictures selected and Open chosen opens ten pictures.
