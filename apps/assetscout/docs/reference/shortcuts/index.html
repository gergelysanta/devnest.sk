Reference

Keyboard shortcuts

Everything AssetScout can be asked to do from the keyboard, and the two things the mouse can do on its own.

Scanning

⌘O Choose a folder and scan it. Not available while a scan is running; a running scan is stopped from the titlebar.

Finding something

⌘F Open the search field in the titlebar and put the cursor in it.
⌘A Select every item the window lists.
⌘J Scroll the selected items back into view.

Looking at a file

Space Open or close Quick Look for the selected items.
⌘Y The same, from the View menu.
⌥⌘I Show or hide the inspector.

Changing files

⌫ Move the selected items to the trash.
⌘⌫ The same, from the File menu.

The application

⌘,Open the settings.
⌘?Open the manual inside the app.
⌘QQuit AssetScout.

The mouse

Double-click Open the file in the application it belongs to.
Right-click Open the menu of everything you can do with the selection. On an empty part of the grid it offers Jump to Selection.
