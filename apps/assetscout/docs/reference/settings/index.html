Reference

Settings

Two panes, six switches. Open them with AssetScout > Settings… or ⌘,.

Generic

Show creation date as item name

On by default. The label under each thumbnail is the date the content was created. Switched off, it is the file name instead.

The date is the better label while you are looking for a moment in time, and it explains the order of the grid. The file name is the better one while you are looking for a particular file. A name too long for the column is shortened; hold the pointer over it to read it whole.

Mark items without a capture date

Off by default. Photos and videos usually carry the moment they were taken. Other files do not, and for those the app falls back on the file's own dates — so a file copied last year gets last year's date whatever its content is, and its place in the list is a guess.

Switch this on and those items are marked. It is off to begin with because in a folder of downloaded files nearly everything would carry the mark, and a mark on everything says nothing.

Ask for confirmation before new scan

On by default. A new scan replaces what is in the window, and the current result is lost. Switch it off if you scan one folder after another and the question is in your way.

Ask for confirmation before moving items to the trash

On by default. Switched off, the files are moved as soon as you ask. They still go to the macOS trash either way, so nothing is lost for good.

File Types

This pane decides which kinds of file a scan collects at all. The rows work exactly like the filter in the titlebar: click a row to switch it, the arrow in front of a group opens the types under it, and All and None switch every row at once.

Two things are different from the filter:

  • It lists every type the app knows, not only the ones the last scan happened to find, and each is written with the extensions it covers — for example .log .txt.
  • The switches are about the next scan. The window in front of you keeps what it already shows, because that is the filter's job.

New scans start with photographs, movies and sound files. Text and documents are known but switched off, so a first scan does not fill the window with configuration files.

Why the list grows

It is built from what macOS itself declares — a few hundred types — plus every type the app has met on disk since it was installed. A kind of file nobody on this Mac had seen before gets a row after the scan that found it.
