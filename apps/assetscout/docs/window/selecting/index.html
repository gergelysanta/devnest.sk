The window

Selecting items

Everything AssetScout can do to a file it does to the whole selection. These are the ways to build one.

Building a selection

ClickSelect one item, dropping whatever was selected before.
⇧-click Select everything between the item you clicked last and this one.
⌘-click Add one item to the selection, or take it out again.
Drag Draw a rectangle over the grid; everything it touches is selected.
⌘A Select every item the window is listing.
Worth knowing

Select All takes what the window lists, not what the scan found. Anything the filter or the search field is hiding stays out of the selection — which is what makes “switch everything else off, then ⌘A” a safe way to act on one kind of file.

Finding your selection again

After scrolling a long way from what you selected, View > Jump to Selection or ⌘J brings it back into view. The same item is in the menu you get by right-clicking an empty part of the grid, which is usually where the pointer already is.

What the selection tells you

With more than one item selected, the inspector stops describing a file and starts describing the set: how many items are selected, and how much room they take together. That is the quick way to answer “what would I get back by deleting these?”. See File info and the map.
