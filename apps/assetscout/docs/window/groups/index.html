The window

Months and groups

The grid is divided into months, and every heading counts what is under it. Which date the division is built from is a choice you can change at any time.

Months, newest first

Items are grouped by the month their content was made, and the months run from the newest downwards. Each heading names the month and counts the items in it.

Click a heading to fold that month away; the arrow on the left turns to show it is folded, and clicking again unfolds it. This is what makes a very large scan usable: when one month holds four thousand pictures, folding it puts the months on either side of it back on the same screen.

Which date builds the months

The button with the two rows of squares in the titlebar opens a short menu with two choices:

Creation Date When the content was made. For a photograph or a video this is read from inside the file, so it survives copying the file to another disk. For everything else it is the older of the two dates the file system keeps. This is what the app starts with.
Last Modified When the file was last written. Use it to find what you worked on recently — a document edited last week, a picture exported again this morning.

The choice changes the month groups, the order of the items inside them, and the date written under each thumbnail. All three always agree, so the label under a thumbnail is the reason it is where it is.

The button is coloured while the grid is grouped by the modification date, and your choice is remembered for the next time you open the app.

Worth knowing

Rotating a file gives it today's modification date. While the grid is grouped by Last Modified, the app asks once per scan whether the files you changed should move to their new month or stay put. See Rotating and flipping.

Where those dates come from, and when they can be wrong, is the subject of Where the dates come from.
