The inspector

File info and the map

The panel on the right shows what is written inside the file you selected. This is the part of it that every file has.

Showing and hiding it

View > Show Inspector, ⌥⌘I, or the button at the right of the titlebar. Before the first scan there is nothing to show, so the inspector stays closed and the button cannot open it; it comes back on its own with the first scan.

With nothing selected it says No Selection.

File Info

Whatever you select, this section is there:

Path Where the file is. The arrow at the end of the row shows it in the Finder.
Type The kind of file, written the way macOS names it.
Size The file's size on disk, as the Finder reports it.
Created, Modified The file's own two dates. Note that these are the file dates — for a photograph the moment it was taken is further down, under Date & Time.
Dimensions In pixels, for pictures and videos.

Every section has an arrow in front of its title: click the title to fold it away, click again to open it. All the values can be selected with the mouse and copied.

The map

Pictures, videos and sound files get a map at the top of the panel. When the file carries GPS coordinates the map is zoomed in on the place and a marker shows it — a camera for a photograph, a film symbol for a video. A file without coordinates gets a plain map and no marker.

More than one file

With several items selected the inspector stops describing a file and describes the set: how many items, and how much room they take together. It is the quickest way to see what deleting a selection would win back.

To look at the file itself rather than what is written about it, use Quick Look — see Looking at a file.
