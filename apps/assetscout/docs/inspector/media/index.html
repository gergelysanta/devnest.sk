The inspector

Video, audio, text and documents

Video, audio, text and documents each report something different about themselves. Here is what each one has.

Video

A video gets two extra sections. Video Properties gives the duration, the codec, the bitrate and the frame rate. Audio Properties gives the codec, the number of channels and the sample rate of the sound track. A video with no sound track has only the first of them.

The panel can play it, and so can Quick Look — see Looking at a file.

Audio

One Audio Properties section: the duration, the codec, the bitrate, the number of channels, the sample rate and the bit depth.

Sound files carry no capture date the app can rely on, so they are always placed by their file dates. A voice memo copied from a phone will sit in the month it was copied.

Text

A Text Properties section with the number of words, lines and characters, and the language the text appears to be written in.

Text files are known to the app but switched off for a new scan, so you will only see this after switching the group on in the File Types settings and scanning again.

Documents

A document such as a PDF gets two sections.

  • Document Metadata — what the program that made the file wrote into it: title, author, subject, creator, producer, the dates and the language.
  • Document Properties — the number of pages, words and characters, and whether the document is encrypted.

Rows the file has nothing for are left out entirely, so a document written without a title has no Title row rather than an empty one.
