AssetScout for macOS

You know when you made it.
Not where you put it.

AssetScout walks a folder — or a whole drive — and lays out every picture, video, recording and document it finds as a grid of thumbnails, in the order the content was made. You look for the file by its date instead of by its folder.

Download on the Mac App Store Read the manual

macOS 14.4 or newer Sandboxed — it reads only what you hand it No account, no sync, nothing uploaded

Why

Saved once, and then gone

A photo, a screen recording or a scanned document gets saved somewhere, once. Months later you want it back. You remember roughly when it happened. You do not remember the folder, and searching by name only works if you gave it one.

AssetScout answers the question you can actually answer. Hand it a folder, an old backup, an external disk. It reads everything inside, works out when each file was really made, and puts the whole lot on a timeline.

  • Three ways in. Choose a folder from the titlebar, drop folders on the window, or press ⌘O.
  • The folders nobody can find. Mail attachments, Messages attachments and the system's live wallpapers are offered by name.
  • It remembers. A folder scanned once is still reachable after you quit and start the app again.

What it does

Read the disk, then read the files

Three parts, in the order you meet them: a scan that tells you how far it has got, a window grouped by month, and a panel that changes with whatever you click on.

A scan that says how far it has got

The scan runs in two steps, and the progress bar behaves differently in each. The first walks the directory tree and collects the files worth opening; it does not yet know how many there will be, so the bar only shows that something is happening. Once the total is known, the second step opens each file that can carry a date of its own, and the bar fills up for real.

Results arrive while the scan is still running, so the window fills up as it works — you can select, look at and delete files before it has finished. The stop button ends it whenever you want, and what has been found so far stays in the window.

  • It stays out of other apps. The scan never enters Library/Containers, where a read waits for an answer that never comes.
  • It skips the copies. Inside a Photos, iPhoto or Aperture library it reads the imported originals and leaves the previews, thumbnails, rendered edits and caches alone.
  • It uses the whole machine. The work is spread across as many processor cores as your Mac has.

How a scan works, step by step

Grouped by the month it was made, not the month it was copied

For photographs and videos the date comes from the file's own metadata, which is the moment the picture was taken. A picture copied off a camera last week still lands in the month it was taken in. Files that carry no such date are placed by their file dates instead, and those items can be marked, so you can see at a glance where the order is a guess.

A button in the titlebar chooses which date the months are built from: Creation Date, or Last Modified for finding what you worked on recently. The choice changes the groups, the order inside them and the date under each thumbnail together, so all three always say the same thing.

Narrowing down is two controls that work together. The filter switches whole kinds of file off — or individual types, JPEG but not PNG — and counts what it is hiding. ⌘F opens the search field, which filters the whole scan by file name as you type.

Where the dates come from

One panel, and it changes with the file

Every file gets a File Info section: where it is, what kind of file macOS thinks it is, its size and its dates — and its dimensions, if it has any. Above that sits a map, zoomed in on the place with a camera or a film marker when the file carries GPS coordinates.

  • Photographs — the EXIF the camera wrote, in up to four sections: camera, lens, date and everything else.
  • Video — duration, codec, bitrate and frame rate, plus the same for the sound track when there is one.
  • Audio — duration, codec, bitrate, channels, sample rate, bit depth.
  • Text — words, lines, characters, and the language the text seems to be in.
  • Documents — what the program that made the file wrote into it, and the page, word and character counts.
  • Several files at once — how many are selected and how much room they take together.

EXIF numbers are explained rather than printed raw. The metering mode, the flash bitfield and the exposure time are given as words, and as the values a photographer reads. A tag the app does not know is not thrown away — it goes under Other, named the way the file names it.

Actions

Finding it is usually not the end of it

Select what you want — click, ⇧-click for a run, ⌘-click for one more, or drag a rectangle over the grid — and every action works on the whole selection.

Select

⌘A takes everything the window lists — what the filter and the search field hide stays out of it. Scrolled away from your selection, ⌘J brings it back into view.

Look, turn, throw away

Space opens Quick Look — which is also how you play a video or a sound file. The bottom four items appear for pictures and videos and are written to the file on disk.

Drag them out

Drop the selection on a folder in the Finder, or on any app that takes files. That moves them, as dragging in the Finder does; hold ⌥ while you drop to copy instead.

Your files

It reads what you hand it, and nothing else

AssetScout is fully sandboxed. It starts with access to nothing at all, and gains the right to read a folder only when you choose that folder yourself. Picking ~/Pictures says nothing about ~/Documents.

That permission is kept in a security-scoped bookmark, so a folder scanned once is still readable after a restart and you are not asked for it twice.

There is no account, no sync and no server to talk to. Nothing is uploaded, and no library is built beside your files. Reading a photograph's date does not even decode the picture.

The sandbox and your files

  • Rotating and flipping Writes the turned picture back into the file. There is no undo, and no copy is kept.
  • Move to Trash Puts the file in the macOS trash, where it stays until you empty it.
  • Dragging a thumbnail out Moves the file where you dropped it, or copies it with ⌥ held down.

Those three are the only things that change a file, and each of them is something you chose from a menu.
